# Portfolio
DARSHAN PATEL — PYTHON & DJANGO BACKEND DEVELOPER PORTFOLIO

A bespoke, responsive single-page portfolio for Darshan Patel (Python & Django Developer), featuring editorial serif headlines, warm amber-gold highlights, deep near-black background, and comprehensive sections for Home, About, Projects, Skills, and Contact.

--------------------------------------------------
QUICK START:
--------------------------------------------------
1. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
2. For local development with live reloading, open this folder in VS Code and use the "Live Server" extension, or run:
   python -m http.server 8000
   and navigate to http://localhost:8000 in your browser.

--------------------------------------------------
FILES INCLUDED:
--------------------------------------------------
- `index.html`: Complete semantic HTML5 structure populated with Darshan's verified CV:
    #home (Hero & Brand), #about (Experience, Philosophy & Education), #projects (Featured Work & Architecture: Collect Eaze, Trading Platforms, Core APIs), #skills (Categorized Toolkit: Python, Django, Redis/Celery, Databases, Integrations), #contact (Direct Channels, Phone, Mailto Form), and Site Footer.
- `styles.css`: Fully responsive CSS design system with custom variables, seamless section merging, high-contrast Playfair Display serif typography, DM Sans UI labels, and mobile/tablet breakpoints.
- `script.js`: Interactive enhancements including mobile menu toggle, scroll-aware sticky navigation bar with active indicators (IntersectionObserver), copy-to-clipboard email utility, and mailto form dispatcher.
- `assets/Darshan_Patel_CV.pdf`: Darshan's verified Resume PDF linked directly to "Download CV" buttons in Navigation, Hero, Contact, and Footer.
